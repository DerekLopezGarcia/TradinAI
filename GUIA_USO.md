# 🎯 Guía Rápida - Sistema de Análisis de IA

## ¿Cómo Usar el Análisis de IA?

### 1️⃣ **Seleccionar un Activo**
   - Abre la aplicación
   - Selecciona un símbolo de la lista (BTCUSD, EURUSD, AAPL, etc.)

### 2️⃣ **Seleccionar Timeframe**
   - Usa el selector de timeframe (1m, 5m, 15m, 1h, 4h, 1d, etc.)
   - El gráfico se actualizará automáticamente

### 3️⃣ **Esperar Datos**
   - El gráfico cargará los datos de velas
   - Una vez cargado (mínimo 20 velas), aparecerá el panel de análisis

### 4️⃣ **Ejecutar Análisis**
   - **Busca el botón "Ejecutar Análisis"** con el ícono ⚡
   - Está ubicado en la esquina superior derecha del panel de análisis
   - **Haz clic en el botón**

### 5️⃣ **Ver Resultados**
   El análisis mostrará:
   
   📊 **Resumen Rápido**
   - Tendencia (Alcista/Bajista)
   - Sentimiento general
   - Predicción
   - Nivel de confianza

   📋 **Secciones Detalladas** (expandibles)
   - **Tendencia**: Análisis de estructura y ADX
   - **Patrones**: Velas especiales detectadas
   - **Indicadores**: RSI, MACD, Bollinger, Stochastic, ATR
   - **Predicción**: Objetivos de precio y stop loss
   - **Riesgo**: Factores de riesgo
   - **Resumen**: Conclusión ejecutiva

### 6️⃣ **Actualizar Análisis**
   - Puedes hacer clic nuevamente en el botón para actualizar
   - Útil si cambias de timeframe o quieres reanalizar con los datos actuales

## 💡 ¿Qué Significa Cada Sección?

### Tendencia
- Muestra si el mercado sube (alcista), baja (bajista) o se mueve lateralmente
- Se basa en los máximos y mínimos de las últimas velas
- El ADX (>25) confirma si la tendencia es fuerte

### Patrones
- Identifica formaciones especiales de velas (dojis, martillos, etc.)
- Explica qué señal da cada patrón
- La confiabilidad muestra cuán probable es que se cumpla

### Indicadores
- **RSI**: Mide si está sobrecomprado (>70) o sobrevendido (<30)
- **MACD**: Muestra el momentum (alcista/bajista)
- **Bollinger**: Bandas de volatilidad
- **Stochastic**: Oscilador para cambios de dirección
- **ATR**: Nivel de volatilidad actual

### Predicción
- Dirección esperada: Bullish (alcista) o Bearish (bajista)
- Probabilidad: Porcentaje de confianza
- Objetivos: Precios hacia donde podría ir
- Stop Loss: Dónde se invalida la predicción
- Riesgo/Beneficio: Ratio de ganancia vs pérdida

## 🐛 Troubleshooting

### "Se requieren al menos 20 velas para análisis"
- El gráfico necesita más datos
- Espera a que cargue completamente

### El botón está deshabilitado
- El análisis se está ejecutando
- Espera a que termine (mostrará "Analizando...")

### No aparece el panel de análisis
- Asegúrate de que el gráfico tenga datos
- Cambia a otro timeframe y vuelve
- Recarga la página
