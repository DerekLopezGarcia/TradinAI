## 🎓 Notas Técnicas

### Variables de Entorno

**Privadas** (no en `.env.example`):
```
TWELVE_DATA_API_KEY=xxx         # Solo en .env.local
QUANDL_API_KEY=xxx              # Solo en .env.local
OANDA_API_KEY=xxx               # Solo en .env.local
```

**Públicas** (OK en `.env.example`):
```
NEXT_PUBLIC_FINNHUB_KEY=xxx     # Se ve en navegador (es seguro)
NEXT_PUBLIC_NEWS_API_KEY=xxx    # Se ve en navegador (es seguro)
```

### Flujo de Datos

```
Tu .env.local (privado)
    ↓
process.env.TWELVE_DATA_API_KEY
    ↓
app/api/market/candles/route.ts
    ↓
fetch a Twelve Data API
```

### Verificación de Seguridad

```
git commit
    ↓
.husky/pre-commit (automático)
    ↓
¿Hay patrones de secretos?
    ├─ SÍ → ❌ Commit rechazado
    └─ NO → ✅ Commit permitido
```
